# Project Guidelines

## Git & GitHub Rules
- **Never** create a GitHub repository unless the user explicitly asks for it.
- **Automatic deployment workflow**: When making code changes, automatically commit and push directly to `main` branch. This triggers Railway auto-deployment.
- **No PR approval required**: User wants rapid iteration without manual approval steps.

## Sensitive Data
- The `data/` directory contains sensitive financial statements and must **never** be committed or included in any PR.
